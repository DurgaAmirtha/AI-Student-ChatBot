AI Student Chatbot

A student support chatbot built using FastAPI and React with Gemini AI integration.  
It helps students with studying, interview preparation, communication practice, and doubt solving through an interactive chat interface.

Features

- Study assistance
- Interview preparation
- Doubt solving
- Communication support
- Smart study planning
- Gemini AI integration

Built With

- React
- Vite
- FastAPI
- Python
- SQLite
- Google Gemini API
